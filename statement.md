# Project Statement

## Project Title
StudyPilot — Student Study & Performance Manager

## Problem Statement
Students often maintain study tasks, practice questions and performance information separately. This makes it difficult to identify weak topics and decide what to study next. StudyPilot provides a single Python-based system for task management, quiz practice, performance analysis and rule-based study recommendations.

## Scope
The project focuses on a console-based student study assistant. It stores study tasks and quiz results locally using JSON files and analyzes quiz performance using Python algorithms and data structures.

## Target Users
- College students
- School students learning programming
- Students preparing for programming examinations

## High-Level Features
- Add, view, complete and delete study tasks
- Practice programming questions
- Calculate quiz accuracy
- Analyze topic-wise performance
- Identify weak topics
- Generate study recommendations
- Display an analytics dashboard
